# v1.3.6

Cumulative release notes for changes on `main` since **v1.3.2**, including the improvements shipped in v1.3.4 and v1.3.5.

## Features and improvements

- Added a browsing history screen and link action panel.
- Added an app-link choice sheet with remembered preferences for opening links in Drift or an external app.
- Added language settings and expanded Spanish, Arabic, and Chinese translations.
- Added animated settings switches and a consistent in-app alert dialog.

## Bug fixes

- Restored WebView rendering after the React Native 0.86 migration.
- Fixed render-loop issues and stabilized shell rendering and tab metadata updates.
- Fixed crashes caused by an unavailable persisted language.
- Improved handling of non-web URL schemes by handing them off from the WebView.

## Platform, build, and release tooling

- Upgraded Expo, React Native, and related dependencies.
- Added an interactive release helper, automatic next-patch version suggestions, and release notes generated from conventional commits.
- Updated tag releases to build Android only and fixed EAS CLI setup in GitHub Actions.
- Improved Android release publishing so successful builds include download links even when the runner cannot attach the APK.
- Updated the user guide and documented the rebase-only Git workflow.

## Scope

This release is based on `main`. The unmerged Android Picture-in-Picture implementation and follow-up plan are **not included**.
